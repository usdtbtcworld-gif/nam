# CONNECT MEET

Telegram-бот знакомств: анкета, проверка фото модератором, приглашения,
подтверждение встречи по QR-коду и геолокации, 1 MEET за встречу.
Тестовый режим: никаких реальных платежей.

Сервер и мини-приложение в одном проекте, без внешних библиотек (нужен Node.js 20+).

## Запуск на Render

1. Загрузи эти файлы в новый репозиторий на GitHub.
2. На render.com: New → Web Service → выбери репозиторий.
3. Настройки:
   - Runtime: Node
   - Build Command: `echo ok`
   - Start Command: `node server.js`
   - Instance Type: Free
4. Environment Variables:
   - `BOT_TOKEN` — токен бота из @BotFather
   - `ADMIN_ID` — твой Telegram ID (необязательно; без него админом станет первый, кто нажмёт /start)
5. Deploy. Сервер сам подключит бота и поставит кнопку «Открыть».

## Как это работает

- `/start` в боте → приветствие и кнопка «Открыть CONNECT MEET».
- Анкета (18+) → фото → фото уходит админу в бот с кнопками «Одобрить / Отклонить».
- После одобрения можно приглашать людей. Приглашённому приходит сообщение в бот.
- Встреча: один нажимает «Показать QR», второй «Сканировать». Оба должны быть
  не дальше 300 м друг от друга. Каждый получает 1 MEET. С одной парой — раз в сутки.

## Важно про бесплатный Render

- Сервер засыпает через 15 минут без дела. Первое сообщение будит его примерно за минуту.
- Данные хранятся в папке `data/` и сбрасываются при новом деплое или перезапуске.
  Для настоящего запуска нужен постоянный диск или база данных.
